依次写：
- ATS 风险：提取顺序与格式风险、关键词现状和需要证实的补充方向、动词与职责描述。
- 可放大的亮点：具体经历 + 能力依据。
- 需要修复的问题：原句/位置 + 面试影响 + 修复动作。
- 行业对照：项目深度 / 量化成果 / 技能 / 协作，列“岗位需要、原文证据、差距、依据性质”。
- 修复优先级：紧急 / 重要 / 时间充裕时，各项具体可执行。

## 模板 B-0：待自评

围绕优先级最高的具体技能写出三道题：
1. 能否解释该技能的核心概念及边界？
2. 是否完成过该技能的具体任务？请描述一次实际操作。
3. 是否能把流程、结果和局限系统讲给面试官？

每题可选 A 不会 / B 理论了解 / C 有实践但表达不完整 / D 独立完成且能表达。A 从概念开始；B 缩减概念、强化实践；C 从方法后半段与表达开始；D 重点模拟追问。混合结果按具体薄弱项安排，不能机械取多数掩盖某项缺口。

未作答时：标“待自评”，不能写“你的自评结果显示……”。

## 模板 B-2：有自评后的学习路线

说明技能目标、自评依据、时间预算，再按阶段列：具体任务 → 可检查产出 → 自检标准。

| 阶段 | 时间比例 | 目标产出 |
| --- | --- | --- |
| 概念框架 | 20% | 能向外行解释关键概念 |
| 核心方法 | 50% | 独立完成一个贴近岗位的小任务 |
| 面试语言 | 30% | 2 分钟真实案例表达和三层追问答题卡 |

附：1–2 天极速版的三件关键事项；暂缓学习项及理由。未检索资源时不要伪造课程链接。

## 行业追问适配

| 方向 | 追问侧重点 |
| --- | --- |
| 互联网 / 技术 | 方案取舍、实现细节、指标口径与故障边界 |
| 金融 / 财税 | 专业概念、数据精度、风险识别；时效性规则另行核实 |
| 咨询 | 问题定义、结构化拆分、假设与验证 |
| 外企 | 行为案例、个人贡献、协作与英文表达 |
| 创业公司 | 资源约束、交付结果、职责范围与迭代 |
| 国企 / 央企 | 岗位基本要求、规范流程、协作和职责边界 |

这些是追问组织线索，不能当作每家公司一致的选人规则。
